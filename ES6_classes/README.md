# ES6 Classes

A project exploring ES6 Class syntax, inheritance, getters/setters, static methods, and metaprogramming with Symbols.

## Learning Objectives

- How to define a Class
- How to add methods to a class
- Why and how to add a static method to a class
- How to extend a class from another
- Metaprogramming and symbols

## Setup

```bash
npm install
npm run test
npm run full-test
```
